sdkProfessor Desktop App
-----------------------

A desktop app that reads Python code aloud like a professor, explains it with AI, and quizzes you on what you learned.

INSTRUCTIONS:
1. Set your OpenAI API key in your environment:
   export OPENAI_API_KEY=yourkeyhere

2. Run the GUI:
   python gui.py

REQUIREMENTS:
- Python 3.9+
- PyQt6
- pyttsx3
- openai
